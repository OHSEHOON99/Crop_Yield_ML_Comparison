# Results

This folder contains curated result tables from the wheat yield modeling experiments.

## Experiment Folders

- `11_20/`: model outputs using the 2011-2020 evaluation-year setup
- `12_20/`: model outputs using the 2012-2020 evaluation-year setup

Each folder contains:

- `*_metrics.csv`: yearly, total, and standard-deviation metrics
- `*_results.csv`: true and predicted yield by region and year
- `hyperparams/*_best_params.csv`: selected model hyperparameters

The result files are small enough to inspect directly in GitHub and are kept as public reference outputs for the repository.
